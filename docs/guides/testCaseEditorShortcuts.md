# Test case editor shortcuts

> Every key the test case editor answers to, on one page. The editor is where a
> test set's test cases are written.

## Reading and moving

| Key                                                     | What it does                            | Read more                                                    |
|---------------------------------------------------------|-----------------------------------------|--------------------------------------------------------------|
| `Ctrl+F`                                                | Puts the cursor in the search box       | [Search test cases](../editorPanel/searchTestCases.md)       |
| `Ctrl+Right`, `Ctrl+Alt+Cmd+Right` on a Mac             | The next page                           | [Page through](../editorPanel/pageThrough.md)                |
| `Ctrl+Left`, `Ctrl+Alt+Cmd+Left` on a Mac               | The previous page                       | [Page through](../editorPanel/pageThrough.md)                |
| `Ctrl+Shift+Right`, `Ctrl+Alt+Shift+Cmd+Right` on a Mac | The last page                           | [Page through](../editorPanel/pageThrough.md)                |
| `Ctrl+Shift+Left`, `Ctrl+Alt+Shift+Cmd+Left` on a Mac   | The first page                          | [Page through](../editorPanel/pageThrough.md)                |
| `Enter`                                                 | Opens the details panel, or a grid cell | [Open the details panel](../editorPanel/openDetailsPanel.md) |
| `Escape`                                                | Steps back one step                     | [Step back](../editorPanel/stepBack.md)                      |
| `Context Menu`                                          | Opens the menu on the selection         | [The keyboard menu](../editorPanel/keyboardMenu.md)          |
| `Ctrl` and the wheel                                    | Changes the text size                   | [Change the text size](../setting/changeTextSize.md)         |

## Writing test cases

| Key                                 | What it does                                    | Read more                                              |
|-------------------------------------|-------------------------------------------------|--------------------------------------------------------|
| `Ctrl+M`, `Ctrl+Alt+Cmd+M` on a Mac | Creates a test case                             | [Create a test case](../editorPanel/createTestCase.md) |
| `F2`                                | Opens the menu of fields to change              | [Change one field](../editorPanel/changeOneField.md)   |
| `D` `E` `M` `T` `B` `S` `P` `G` `O` | Opens that one field straight away              | [Change one field](../editorPanel/changeOneField.md)   |
| `Delete`                            | Removes the selected test cases                 | [Remove test cases](../editorPanel/removeTestCases.md) |
| `Ctrl+Z`                            | Takes back the last change                      | [Undo a change](../editorPanel/undoChange.md)          |
| `Ctrl+Y`                            | Puts it back                                    | [Redo a change](../editorPanel/redoChange.md)          |
| `Ctrl+Enter`                        | A line break inside a grid cell or a long field | [Edit a grid cell](../editorPanel/editGridCell.md)     |

The letters open one field each:

| Letter | Field           |
|--------|-----------------|
| `D`    | Description     |
| `E`    | Expected Result |
| `M`    | Module          |
| `T`    | Test Data       |
| `B`    | Pre Conditions  |
| `S`    | Steps           |
| `P`    | Priority        |
| `G`    | Group           |
| `O`    | Order           |

## The clipboard

| Key      | What it does                                                                            | Read more                                             |
|----------|-----------------------------------------------------------------------------------------|-------------------------------------------------------|
| `Ctrl+C` | On cards, opens the copy menu; a letter copies one value. In the grid, copies the cells | [Copy as text](../editorPanel/copyAsText.md)          |
| `Ctrl+X` | In the grid, copies the cells and empties the ones that can be typed into               | [The grid clipboard](../editorPanel/gridClipboard.md) |
| `Ctrl+V` | In the grid, pastes text into the cells                                                 | [The grid clipboard](../editorPanel/gridClipboard.md) |

**Copy Test Case**, **Cut Test Case** and **Paste Test Case** have no key. They
are on the right-click menu.

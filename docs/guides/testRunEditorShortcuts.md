# Test run editor shortcuts

> Every key the test run editor answers to, on one page. The editor is where a
> test run is executed.

## Reading and moving

| Key                                                     | What it does                            | Read more                                                    |
|---------------------------------------------------------|-----------------------------------------|--------------------------------------------------------------|
| `Ctrl+F`                                                | Puts the cursor in the search box       | [Search test cases](../editorPanel/searchTestCases.md)       |
| `Ctrl+Right`, `Ctrl+Alt+Cmd+Right` on a Mac             | The next page                           | [Page through](../editorPanel/pageThrough.md)                |
| `Ctrl+Left`, `Ctrl+Alt+Cmd+Left` on a Mac               | The previous page                       | [Page through](../editorPanel/pageThrough.md)                |
| `Ctrl+Shift+Right`, `Ctrl+Alt+Shift+Cmd+Right` on a Mac | The last page                           | [Page through](../editorPanel/pageThrough.md)                |
| `Ctrl+Shift+Left`, `Ctrl+Alt+Shift+Cmd+Left` on a Mac   | The first page                          | [Page through](../editorPanel/pageThrough.md)                |
| `Enter`                                                 | Opens the details panel, or a grid cell | [Open the details panel](../editorPanel/openDetailsPanel.md) |
| `Escape`                                                | Steps back one step                     | [Step back](../editorPanel/stepBack.md)                      |
| `Context Menu`                                          | Opens the menu on the selection         | [The keyboard menu](../editorPanel/keyboardMenu.md)          |
| `Ctrl` and the wheel                                    | Changes the text size                   | [Change the text size](../setting/changeTextSize.md)         |

## Executing a test run

| Key                                | What it does                                                     | Read more                                                             |
|------------------------------------|------------------------------------------------------------------|-----------------------------------------------------------------------|
| `P`                                | Records **Passed**                                               | [Record a pass](../editorPanel/recordPassed.md)                       |
| `F`                                | Records **Failed**, and asks why                                 | [Record a failure](../editorPanel/recordFailed.md)                    |
| `B`                                | Records **Blocked**                                              | [Record a block](../editorPanel/recordBlocked.md)                     |
| `F2`                               | Changes the failure details without changing the run item status | [Change the failure details](../editorPanel/editFailureDetail.md)     |
| `F5`                               | Runs the selected test cases, or stops them                      | [Run a test case](../editorPanel/runOneTestCase.md)                   |
| `Shift+F5`                         | Goes to the automation code                                      | [Go to the code](../codegen/goToCode.md)                              |
| `F12`, `Ctrl+Alt+Cmd+F12` on a Mac | Writes the method for a test case that has none                  | [Automate a test case](../codegen/automateTestCase.md)                |
| `Ctrl+P`, `Ctrl+Alt+P` on a Mac    | Generates a report on this test run                              | [Generate a report](../report/generateReport.md)                      |

**Start Manual Execution**, **Stop Execution** and **Result Analysis** have no
key. They are on the editor's toolbar.
